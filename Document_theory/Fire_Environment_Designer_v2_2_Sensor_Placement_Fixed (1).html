Design Summary

Reference & Placement Basis

Important: the project file supports the sensing roles and lists the device datasheets. It does not prescribe certified installation coordinates. Therefore, XYZ positions generated here are clearly marked as geometry-based engineering heuristics for conceptual test-chamber design.
PROJECT SOURCE
Spatiotemporal Vision and Sensor Fusion for Robust Fire Detection in Dusty Environments

The project architecture uses RGB vision with Thermal Array, CO and PM sensing. Thermal and CO are used as confirmation channels for combustion-related evidence, while PM supports separation of dust/smoke particulate conditions.

REFERENCED IN PROJECT
MLX90640 32×24 IR Array Datasheet — Melexis

Listed in the project references for the thermal-array device. Exact FOV/package and installation constraints must be verified for the part actually purchased.

REFERENCED IN PROJECT
ZE03 Electrochemical CO Module Datasheet — Winsen

Listed in the project references for CO measurement. Final enclosure, airflow exposure and mounting instructions must follow the selected module documentation.

REFERENCED IN PROJECT
PMS5003 Datasheet — Plantower

Listed in the project references for particulate measurement. Final inlet/outlet orientation and airflow clearance must be checked against the actual sensor documentation.

SIMULATOR HEURISTIC
Placement algorithm used in this v2

Thermal: upper corners/perimeter with line-of-sight toward the room volume. CO: distributed wall/perimeter nodes at a representative vertical level. PM: representative interior sampling positions with wall clearance. Coordinates scale automatically with room dimensions and device quantity.

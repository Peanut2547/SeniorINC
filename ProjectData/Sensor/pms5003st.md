# PMS5003ST

## หลักการทำงาน

PMS5003ST ตรวจวัดฝุ่นด้วยหลักการ **Laser Scattering** โดยพัดลมภายในจะดูดอากาศเข้าสู่ห้องวัด เมื่ออนุภาคฝุ่นผ่านแสงเลเซอร์จะทำให้แสงเกิดการกระเจิง ตัวรับแสงจะตรวจจับสัญญาณ แล้วนำไปคำนวณขนาด จำนวน และความเข้มข้นของอนุภาคฝุ่นในอากาศ

รุ่น PMS5003ST ยังสามารถวัด **ฟอร์มัลดีไฮด์ (HCHO), อุณหภูมิ และความชื้นสัมพัทธ์** ได้

## ความสามารถของเซนเซอร์

- วัดค่าความเข้มข้นของฝุ่น PM1.0, PM2.5 และ PM10 หน่วย `µg/m³`
- นับจำนวนอนุภาคขนาดมากกว่า 0.3, 0.5, 1.0, 2.5, 5.0 และ 10 µm
- วัดความเข้มข้นของฟอร์มัลดีไฮด์ (HCHO)
- วัดอุณหภูมิ
- วัดความชื้นสัมพัทธ์
- ตรวจจับอนุภาคขนาดเล็กได้ประมาณ 0.3 µm
- ส่งข้อมูลแบบดิจิทัลผ่าน UART
- รองรับ Active Mode, Passive Mode และ Sleep Mode

## การเชื่อมต่อกับ ESP32

กำหนดขารับข้อมูลเป็น GPIO16 และขาส่งข้อมูลเป็น GPIO17

| ขา PMS5003ST | ขา ESP32 | หน้าที่ |
| --- | --- | --- |
| VCC — Pin 1 | 5V/VIN | จ่ายไฟให้เซนเซอร์ |
| GND — Pin 2 | GND | กราวด์ร่วม |
| RX — Pin 4 | GPIO17 / TX2 | รับคำสั่งจาก ESP32 |
| TX — Pin 5 | GPIO16 / RX2 | ส่งข้อมูลไปยัง ESP32 |

## การสื่อสาร

| รายการ | ค่า |
| --- | --- |
| รูปแบบ | UART TTL 3.3 V |
| Baud rate | 9600 bps |
| Data bits | 8 bits |
| Parity | None |
| Stop bit | 1 bit |

เมื่อเปิดเครื่อง เซนเซอร์จะเริ่มทำงานใน **Active Mode** และส่งข้อมูลออกมาอัตโนมัติ โดยเฟรมข้อมูลของ PMS5003ST มีความยาว **40 ไบต์**

## ตัวอย่างผลลัพธ์

```
PM1.0 Average : 12.40 µg/m³
PM2.5 Average : 18.20 µg/m³
PM10 Average  : 24.60 µg/m³
```

จากตัวอย่าง ค่าเฉลี่ยความเข้มข้นของฝุ่น PM1.0 เท่ากับ `12.40 µg/m³` ค่าเฉลี่ย PM2.5 เท่ากับ `18.20 µg/m³` และค่าเฉลี่ย PM10 เท่ากับ `24.60 µg/m³`

## การอ่านค่าจำนวนอนุภาค

PMS5003ST สามารถอ่านค่าฝุ่นในรูปแบบ **จำนวนอนุภาคต่ออากาศ 0.1 ลิตร** โดยแยกตามขนาดอนุภาคที่มากกว่า 0.3, 0.5, 1.0, 2.5, 5.0 และ 10 µm

## ข้อควรระวัง

- ห้ามปิดช่องลมเข้าและช่องลมออกของเซนเซอร์
- หลีกเลี่ยงการติดตั้งใกล้พัดลมแรงหรือแหล่งไอน้ำโดยตรง
- หลังเปิดเครื่องควรรอให้เซนเซอร์วอร์มอัปประมาณ 30 วินาทีก่อนนำค่าที่วัดได้ไปใช้งาน
